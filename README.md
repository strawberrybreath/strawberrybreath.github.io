# Strawberry Breath · 草莓味口气

这是一个属于个人的分享与记录空间。

我喜欢观察，也喜欢表达。电影、书、历史、女性主义，或是日常生活里偶然冒出来的想法，都可能成为这里的内容。比起给兴趣和观点划定边界，我更愿意保持好奇，慢慢记录那些让我在意、值得思考的事情。

**访问网站：** https://strawberrybreath.github.io/

## 网站内容

- **首页（`index.html`）**：介绍网站与作者，展示最新三篇文章、联系方式。
- **文章列表（`articles.html`）**：收录全部五篇文章，按发布时间由新到旧排列，并支持关键词搜索。
- **第1篇（`article-01.html`）**：《她不是谁的“小姐”，她只是她自己》——从《Enola Holmes》看女性主体性与自我选择。
- **第2篇（`article-02.html`）**：《女巫不曾消失：从欧洲猎巫到万圣节的女性符号》。
- **第3篇（`article-03.html`）**：《语文课本里的爱情观：重读〈氓〉》。
- **第4篇（`article-04.html`）**：《谁把山河装进了烟盒？二手烟世界里的女性处境》。
- **第5篇（`article-05.html`）**：《大观园的梦醒了，女性的故事却留下了》——从女性视角重读《红楼梦》中的女性情谊、才情与命运。

## 项目文件

- `assets/`：网站使用的图片、字体及样式资源。
- `articles-data.js`：首页最新文章与独立文章列表页共用的数据。
- `progress.js`：文章阅读进度与阅读统计功能。
- `index.html`：网站首页。
- `articles.html`：独立文章列表页。
- `article-01.html` 至 `article-05.html`：五篇已发布文章。

网站通过 GitHub Pages 发布，并适配桌面、平板和手机浏览。
