# Strawberry Breath · 草莓味口气

这是一个属于个人的分享与记录空间。

我喜欢观察，也喜欢表达。电影、书、历史、女性主义，或是日常生活里偶然冒出来的想法，都可能成为这里的内容。比起给兴趣和观点划定边界，我更愿意保持好奇，慢慢记录那些让我在意、值得思考的事情。

**访问网站：** https://strawberrybreath.github.io/

## 网站内容

网站目前包含首页和一篇文章：

- **首页（`index.html`）**：介绍网站与作者，展示文章列表和联系方式。
- **文章（`article-01.html`）**：以电影《Enola Holmes》为起点，聊女性主体性、自我选择，以及那些仍然存在的社会期待。

后续文章会继续展示在首页的文章列表中；目前不设置独立的文章归档页，也不保留旧版栏目页面。

## 项目文件

- `assets/`：网站使用的图片、字体及样式资源。
- `articles-data.js`：首页文章列表的数据。
- `progress.js`：文章阅读进度与阅读统计功能。
- `index.html`：网站首页。
- `article-01.html`：第一篇文章。

网站通过 GitHub Pages 发布，并适配桌面、平板和手机浏览。
