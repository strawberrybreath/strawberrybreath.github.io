# Strawberry Breath · 草莓味口气

一个分享喜欢、记录想法的个人网站。这里会写电影、阅读、历史、女性主义，也会记录生活中的观察与思考。

**网站地址：** https://strawberrybreath.github.io/

## 网站结构

- **首页（`index.html`）**：网站介绍、关于我、最新文章、联系方式。
- **文章（`article-01.html`）**：从《Enola Holmes》出发，讨论女性主体性、自我选择与社会期待。

目前网站只保留首页和第一篇文章。文章列表作为首页中的一个区域呈现，不再单独维护旧版归档页或历史栏目入口。

## 项目文件

- `assets/`：网站实际使用的头像、电影海报、猫咪照片、公众号二维码及样式文件。
- `progress.js`：文章阅读进度与阅读统计。
- `articles-data.js`：首页文章列表数据。

网站使用 GitHub Pages 发布，支持桌面、平板与手机浏览。
