## 关于这个项目 / About the Journal

「草莓味口气」是一份独立女性文化刊物，关注女性电影、女性主义、女性经验，以及一个人如何逐渐建立自己的判断与主体性。

我们从电影出发，也阅读书籍与现实生活中的女性经验。这里不急着给出标准答案，而是尝试认真观看、细致阅读，保留复杂性，并把思考的空间还给每个人。

*Strawberry Breath is an independent journal exploring women, film, culture, feminist ideas, and the ongoing process of becoming oneself. We look closely at stories, read critically, and make room for independent thought rather than easy answers.*

## 编辑与素材原则 / Editorial Principles

- **以具体内容为依据。** 影评尽量结合场景、人物行动、叙事选择与冲突，不以空泛口号代替分析。
- **区分事实与观点。** 影片资料优先参考发行方官方资料；编辑解读应与剧情事实清楚区分。
- **认真核对引用。** 直接引用台词时，核实原文、说话人、影片与场景；未核实的表述不冒充原台词。
- **尊重素材来源。** 海报、剧照与其他视觉素材应注明可核实的来源；公开可访问不代表自动获得转载授权，相关权利归原权利人所有。
- **保持女性视角的开放性。** 关注女性经验，也保留人物、关系与现实处境的复杂性。
