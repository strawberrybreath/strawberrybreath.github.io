# Strawberry Breath · 草莓味口气

一个关于电影、阅读、女性经验与独立思考的个人角落。

**网站：** https://strawberrybreath.github.io/

## 页面

- **首页**：个人介绍、核心想法、第一篇文章推荐与联系方式。
- **第一篇文章**：《她不是谁的“小姐”，她只是她自己》——从《Enola Holmes》看女性主体性、母女关系与自我选择。

## 素材与维护

页面使用仓库内 `assets/` 中的头像、电影海报、猫咪照片、花卉插画与公众号二维码。首页和文章页采用 `assets/two-page.css`，适配桌面、平板与手机。

网站仅保留首页与第一篇文章两个主要页面；旧栏目不再作为独立入口展示。
