# 草莓味口气 · 她的影单

用 GitHub Pages 托管的纯静态分享站点：每期两部电影，不剧透，也不替读者下结论。

- 线上地址：<https://strawberrybreath.github.io/>
- 栏目定位：女性视角的电影分享，主角大多是女人——她们怎么拿主意、怎么在没人看好的地方站稳

## 目录结构

```
index.html            首页（品牌、往期列表、关于、联系）
issue-001/index.html  第 001 期文章页
.nojekyll             关闭 Jekyll 处理，保证静态文件原样输出
```

## 怎么发新一期

1. 在本地生成本期的单页 `issue-XXX/index.html`
2. 在生成脚本的 `ISSUES` 数组里加一条（期号、日期、标题、片目、引言、封面图、链接）
3. 重新生成首页并推送，公众号那边同步排版

## 内容原则

- 只做影片推荐：**不提供、不存放、不代传任何影片文件**
- 海报与剧照版权归各出品方所有，图片来源 TMDB
- 请读者通过正版渠道观看，并遵守当地法律法规

## 技术说明

- 纯静态，零 JavaScript，零第三方统计
- 字体使用系统字体（Songti SC / PingFang SC），不加载外部字体文件
- 配图全部走 TMDB 图床，仓库内不放图片
